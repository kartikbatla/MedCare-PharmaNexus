Flu activity → Paracetamol demand (Delhi, 24 months)

This is the core P1 idea: current ILI surveillance is fed to the model as an exogenous signal, not just calendar month — so a fast-rising flu season shows up as a demand-sensing alert before it fully shows up in sales.
LightGBM, 4-week-ahead horizon, trained on lags + rolling stats + ILI features + calendar/promo. Accuracy is measured against a naive "same as last week" baseline on a held-out final 8 weeks (no leakage — pure time-based split).
